Cara menjalankan progamnya di Intellij IDEA
1. Buka projeknya
2. Buka file nya src/Main.jaba
3. Pencet tombol play/run

Cara jalan di terminal/ CMD
1. buka file nya di terminal
2. abis tu ketik "javac src/*.java" buat compile programnya
3. abis tu ganti dir ke src "cd src", lalu di run make "Java Main"
